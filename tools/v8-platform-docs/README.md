# MCP-сервер документации платформы 1С:Предприятие (Синтакс-Помощник)

MCP-сервер для Cursor / Claude Code, предоставляющий доступ к официальной документации Синтакс-Помощника платформы 1С:Предприятие (роль `platform-docs`).

## Источник данных

Сервер извлекает данные напрямую из установленного дистрибутива 1С:Предприятие (файлы `.hbk` в каталоге `bin` платформы):
- `shcntx_ru.hbk` — контекстный синтакс-помощник (типы, свойства, методы, конструкторы, события, глобальный контекст).
- `shquery_ru.hbk` — язык запросов 1С:Предприятие (встроенные функции, операторы, соединения, разделы запросов).
- `shlang_ru.hbk` — конструкции встроенного языка BSL.
- `mngdsgn_ru.hbk` — элементы и свойства управляемых форм.

Статьи распаковываются, очищаются от HTML и сохраняются в локальную SQLite базу с полнотекстовым индексом FTS5 (`v8_platform_docs.db`, ~27 000 статей).

## Предоставляемые MCP-инструменты

1. **`search_syntax(query, [category], [limit])`**
   - Полнотекстовый и точный поиск по Синтакс-Помощнику.
   - Поддерживает русский и английский синтаксис.
   - Возвращает краткие карточки со ссылками на ID статей.
2. **`get_article(article_id)`**
   - Полный текст статьи документации в формате Markdown.
3. **`get_type_info(type_name)`**
   - Сводная карточка типа платформы (список всех конструкторов, методов, свойств и событий).
4. **`get_method_info(method_name, [type_name])`**
   - Детальное описание метода или глобальной функции: синтаксис, типы параметров, флаги обязательности, возвращаемое значение, контекст выполнения (Сервер / Тонкий клиент / etc.).
5. **`get_query_help(keyword)`**
   - Справка по языку запросов (`КОНЕЦПЕРИОДА`, `ПОЛНОЕ СОЕДИНЕНИЕ`, `ВЫРАЗИТЬ`, `DATEDIFF` и др.).
6. **`check_compatibility(feature_or_method, [type_name])`**
   - Проверка версии платформы, в которой появилась конструкция/метод, и поддерживаемых контекстов.

## Индексация новой версии платформы

Для создания или обновления базы под другую версию платформы:
```bash
python tools/v8-platform-docs/indexer.py "C:\Program Files\1cv8\8.5.4.1878\bin"
```
Индексация занимает ~15-20 секунд.

## Подключение в Cursor

Добавьте в файл `.cursor/mcp.json`:
```json
{
  "mcpServers": {
    "v8-platform-docs": {
      "command": "python",
      "args": [
        "tools/v8-platform-docs/server.py"
      ],
      "env": {
        "PYTHONIOENCODING": "utf-8"
      }
    }
  }
}
```
