# MCP-сервер документации платформы 1С:Предприятие (Синтакс-Помощник)

MCP-сервер для Cursor / Claude Code, предоставляющий доступ к официальной документации Синтакс-Помощника платформы 1С:Предприятие (роль `platform-docs`).

## Источник данных

Сервер извлекает данные напрямую из установленного дистрибутива 1С:Предприятие (файлы `.hbk` в каталоге `bin` платформы):
- `shcntx_ru.hbk` — контекстный синтакс-помощник (типы, свойства, методы, конструкторы, события, глобальный контекст).
- `shquery_ru.hbk` — язык запросов 1С:Предприятие (встроенные функции, операторы, соединения, разделы запросов).
- `shlang_ru.hbk` — конструкции встроенного языка BSL.
- `mngdsgn_ru.hbk` — элементы и свойства управляемых форм.

Статьи распаковываются, очищаются от HTML и сохраняются в локальную SQLite базу с полнотекстовым индексом FTS5 (`v8_platform_docs.db`, ~27 000 статей).

## Предоставляемые MCP-инструменты

1. **`search_syntax(query, [category], [limit])`**
   - Полнотекстовый и точный поиск по Синтакс-Помощнику.
   - Поддерживает русский и английский синтаксис.
   - Возвращает краткие карточки со ссылками на ID статей.
2. **`get_article(article_id)`**
   - Полный текст статьи документации в формате Markdown.
3. **`get_type_info(type_name)`**
   - Сводная карточка типа платформы (список всех конструкторов, методов, свойств и событий).
4. **`get_method_info(method_name, [type_name])`**
   - Детальное описание метода или глобальной функции: синтаксис, типы параметров, флаги обязательности, возвращаемое значение, контекст выполнения (Сервер / Тонкий клиент / etc.).
5. **`get_query_help(keyword)`**
   - Справка по языку запросов (`КОНЕЦПЕРИОДА`, `ПОЛНОЕ СОЕДИНЕНИЕ`, `ВЫРАЗИТЬ`, `DATEDIFF` и др.).
6. **`check_compatibility(feature_or_method, [type_name])`**
   - Проверка версии платформы, в которой появилась конструкция/метод, и поддерживаемых контекстов.

## Требования

- Python 3.10+.
- Пакет `mcp` версии 2 (класс `MCPServer` из `mcp.server.mcpserver`): `pip install "mcp>=2"`. Проверено на `mcp` 2.3.0.
- Установленная платформа 1С:Предприятие: справка берется из ее каталога.

## Индексация

База в репозиторий не коммитится (`.gitignore`): она зависит от установленной у разработчика платформы и собирается локально.

```bash
# Самая новая платформа из стандартных каталогов установки
python tools/v8-platform-docs/indexer.py

# Конкретная версия
python tools/v8-platform-docs/indexer.py "C:\Program Files\1cv8\<версия>\bin"
```

Без аргумента индексатор ищет каталоги версий в `C:\Program Files\1cv8`, `C:\Program Files (x86)\1cv8`, `/opt/1cv8/x86_64`, `/opt/1cv8/i386` и берет самую новую, в которой есть `shcntx_ru.hbk`. Индексация занимает около 10-20 секунд.

## Версия справки и версия проекта

Справка описывает ту платформу, из которой собрана база, а не режим совместимости проекта. Если проиндексирована 8.5, а `{PLATFORM_VERSION}` в `project-profile.md` равен 8.3.24, статья о методе еще не значит, что метод доступен в проекте. Перед использованием метода сверять поле «Появление в версии» (`check_compatibility`) с `{PLATFORM_VERSION}`, а в расширениях - с режимом совместимости расширения (`rules/project-context.md`).

## Границы

- Покрыта только справка платформы: встроенный язык, типы, язык запросов, элементы управляемых форм.
- Программный интерфейс БСП не покрыт: для него навык `skills/bsp-api/SKILL.md`.
- Состав метаданных конфигурации не покрыт: роль `metadata-provider`.

## Роль в пакете

Сервер реализует функциональную роль `platform-docs` (`AGENTS.md`, `workflow/README.md`). Чтобы агенты использовали его, укажите в `workflow/local.md`, в таблице сопоставления ролей: `platform-docs` = `v8-platform-docs`.

## Подключение в Cursor

Добавьте в файл `.cursor/mcp.json`:
```json
{
  "mcpServers": {
    "v8-platform-docs": {
      "command": "python",
      "args": [
        "tools/v8-platform-docs/server.py"
      ],
      "env": {
        "PYTHONIOENCODING": "utf-8"
      }
    }
  }
}
```

## Подключение в Claude Code

Тот же блок `mcpServers` добавляется в `.mcp.json` в корне репозитория, либо командой:

```bash
claude mcp add --transport stdio --env PYTHONIOENCODING=utf-8 v8-platform-docs -- python tools/v8-platform-docs/server.py
```

Путь к `server.py` указан относительно корня репозитория: клиент должен запускать сервер из корня. Файлы `.cursor/mcp.json` и `.mcp.json` личные и не коммитятся.
