# Кейсы платформы и шаблоны исправлений

Каждый кейс построен по схеме: **проблема → симптом → правильный шаблон → ссылка на стандарт ИТС или краткое обоснование**.

---

## 1. Проверка значений на пустоту

**Проблема.** Неверный предикат дает ложные срабатывания на пустых ссылках, неинициализированных переменных и реквизитах со значением по умолчанию.

**Симптом.** Условия вида `Если Контрагент <> Неопределено` пропускают пустые ссылки `Справочники.Контрагенты.ПустаяСсылка()`; `Если ЗначениеЗаполнено(Реквизит)` на форме может вернуть `Истина` для только что инициализированной составной ссылки.

**Шаблон.**

```bsl
// Универсальная проверка «не пусто» для значения любого типа.
Если ЗначениеЗаполнено(Контрагент) Тогда
    // ...
КонецЕсли;
```

Для реквизитов формы со ссылочным или составным типом сначала копировать значение в локальную переменную и проверять ее, чтобы избежать повторного обращения к свойству платформы:

```bsl
ТекущийКонтрагент = Объект.Контрагент;

Если ЗначениеЗаполнено(ТекущийКонтрагент) Тогда
    // ...
КонецЕсли;
```

**Стандарт.** ИТС: «Использование функции ЗначениеЗаполнено».

## 2. Длительные операции

**Проблема.** Прямой запуск фоновых заданий в обход подсистемы БСП «Длительные операции» оставляет интерфейс без индикации прогресса, без обработки отмены и без сериализации результата.

**Симптом.** Клиент зависает, нет индикации прогресса, кнопка «Отмена» ничего не делает, результат теряется при обрыве сети.

**Шаблон.** Использовать `ДлительныеОперации.ВыполнитьФункцию` с правильным форматом имени метода:

```bsl
// На сервере.
Параметры = Новый Структура;
Параметры.Вставить("ДатаНачала", ДатаНачала);
Параметры.Вставить("ДатаОкончания", ДатаОкончания);

ДлительнаяОперация = ДлительныеОперации.ВыполнитьФункцию(
    ПараметрыВыполнения,
    "Отчеты.ПродажиПоПериоду.СформироватьДанныеНаСервере",
    Параметры);
```

- Формат `ИмяВыполняемогоМетода`: `ИмяОбщегоМодуля.ИмяФункции` или `Тип.ИмяОбъекта.ИмяМетода` (без префикса `ОбщийМодуль.`).
- На клиенте подключать `ДлительныеОперацииКлиент.ОжидатьЗавершение` для опроса состояния.
- НЕ передавать в фоновое задание адрес временного хранилища, привязанный к сеансу формы: передавать сериализуемые параметры; при необходимости помещать результат во временное хранилище из самого задания.

**Стандарт.** БСП: подсистема «Длительные операции».

## 3. Временное хранилище: правильные функции

**Проблема.** `ВременноеХранилище` используется как объект, а не как глобальные функции платформы.

**Симптом.** Ошибка: «Метод объекта не обнаружен (Поместить)».

**Шаблон.**

```bsl
// Неправильно
Адрес = ВременноеХранилище.Поместить(Данные, УникальныйИдентификатор);
Данные = ВременноеХранилище.Получить(Адрес);

// Правильно - глобальные функции платформы
Адрес = ПоместитьВоВременноеХранилище(Данные, УникальныйИдентификатор);
Данные = ПолучитьИзВременногоХранилища(Адрес);
```

**Стандарт.** Синтакс-помощник платформы.

## 4. Транзакции в обработчиках событий

**Проблема.** Вложенные транзакции в `ПередЗаписью` / `ПриЗаписи` объекта приводят к двойному `НачалоТранзакции` и неожиданному поведению при откате.

**Симптом.** «Транзакция не активна» при откате, частично сохраненные данные при внутренних ошибках, межсеансовые блокировки.

**Шаблон.** В обработчиках событий записи объекта **не открывать собственную транзакцию**: платформа уже открыла ее. Если нужна внешняя транзакция, открывать ее в вызывающем коде; внутри обработчика `ТранзакцияАктивна()` использовать только для диагностических проверок при необходимости.

```bsl
// В вызывающем коде, который вызывает Записать().
НачалоТранзакции();

Попытка
    Документ.Записать(РежимЗаписиДокумента.Проведение);
    ЗафиксироватьТранзакцию();
Исключение
    ОтменитьТранзакцию();
    ВызватьИсключение;
КонецПопытки;
```

**Стандарт.** ИТС: «Использование транзакций».

## 5. Копирование объектов и табличных частей

**Проблема.** Вызов несуществующего или неверного метода `Копия()` вместо `Скопировать()`.

**Симптом.** «Метод объекта не обнаружен», потерянные строки табличных частей при ручном копировании в цикле.

**Шаблон.**

```bsl
// Таблица значений.
КопияТаблицы = ИсходнаяТаблица.Скопировать();

// Структура.
КопияСтруктуры = Новый Структура;
Для Каждого КлючИЗначение Из ИсходнаяСтруктура Цикл
    КопияСтруктуры.Вставить(КлючИЗначение.Ключ, КлючИЗначение.Значение);
КонецЦикла;

// Документ как совершенно новый объект.
НовыйДокумент = Документы.РеализацияТоваровУслуг.СоздатьДокумент();
ЗаполнитьЗначенияСвойств(НовыйДокумент, ИсходныйДокумент, , "Номер,Дата,ПометкаУдаления,Проведен");
НовыйДокумент.Товары.Загрузить(ИсходныйДокумент.Товары.Выгрузить());
```

**Примечание.** Для документов нужно очистить `Номер`, `Дата`, `ПометкаУдаления`, `Проведен`, иначе платформа может попытаться перезаписать исходный.

## 6. Время на сервере

**Проблема.** `ТекущаяДата()` на сервере дает разные значения на узлах кластера и игнорирует часовой пояс сеанса.

**Симптом.** Документы с датой «из будущего» или «из прошлого», когда пользователи работают в разных часовых поясах; рассогласованные журналы и проведения.

**Шаблон.**

```bsl
// На сервере - НЕ использовать
Текущая = ТекущаяДата();

// На сервере
Текущая = ТекущаяДатаСеанса();

// На клиенте ТекущаяДата() допустима, но предпочтительно получать дату с сервера
```

**Стандарт.** ИТС: «Использование функций для работы с датой и временем».

## 7. Поиск в коллекциях: выбор по сложности

**Проблема.** Линейный `Найти()` / `НайтиПоЗначению()` в больших коллекциях - O(n) на вызов; в цикле получается O(n²).

**Шаблон.**

- До ~100 элементов - `Найти()` / `НайтиПоЗначению()` допустимы.
- От ~1000 элементов или в цикле - построить индекс на `Соответствие`, поиск станет O(1):

```bsl
ИндексПоИНН = Новый Соответствие;

Для Каждого Строка Из ТаблицаКонтрагентов Цикл
    ИндексПоИНН.Вставить(Строка.ИНН, Строка.Контрагент);
КонецЦикла;

// Поиск O(1) в последующих циклах.
Контрагент = ИндексПоИНН.Получить(ИНН);
```

- Для частого поиска по нескольким ключам - `ТаблицаЗначений.Индексы.Добавить("Поле1, Поле2")` + `НайтиСтроки(Структура)` для индексированного линейного поиска.

## 8. Внешние компоненты на тонком клиенте

**Проблема.** Синхронное подключение внешней компоненты блокирует интерфейс и не работает в веб-клиенте.

**Шаблон.** Использовать асинхронную форму через `НачатьПодключениеВнешнейКомпоненты` + `ОписаниеОповещения`:

```bsl
&НаКлиенте
Процедура ПодключитьСканер()
    Оповещение = Новый ОписаниеОповещения("ПослеПодключенияСканера", ЭтотОбъект);
    НачатьПодключениеВнешнейКомпоненты(Оповещение, "ОбщийМакет.СканерКомпонента", "Сканер", ТипВнешнейКомпоненты.Native);
КонецПроцедуры

&НаКлиенте
Процедура ПослеПодключенияСканера(Подключено, ДополнительныеПараметры) Экспорт

    Если Не Подключено Тогда
        ОбщегоНазначенияКлиент.СообщитьПользователю(
            НСтр("ru = 'Не удалось подключить сканер.'"));
        Возврат;
    КонецЕсли;

    // ...
КонецПроцедуры
```

**Стандарт.** ИТС: «Внешние компоненты, асинхронный интерфейс».

## 9. Управляемые блокировки и предотвращение взаимоблокировок

**Проблема.** Отсутствие или неверные управляемые блокировки вызывают конфликты чтения и записи при проведении; непоследовательный порядок блокировок в разных документах приводит к взаимоблокировкам.

**Симптом.** Эпизодические «Конфликт блокировок при выполнении транзакции», взаимоблокировки под нагрузкой (особенно при проведении документов), чтение незафиксированных данных, рассогласование остатков после параллельного проведения.

**Шаблон - установить управляемую блокировку до чтения остатков регистра при проведении:**

```bsl
Процедура ОбработкаПроведения(Отказ, РежимПроведения)

    Блокировка = Новый БлокировкаДанных;

    ЭлементБлокировки = Блокировка.Добавить("РегистрНакопления.ТоварыНаСкладах");
    ЭлементБлокировки.Режим = РежимБлокировкиДанных.Исключительный;
    ЭлементБлокировки.ИсточникДанных = Товары;
    ЭлементБлокировки.ИспользоватьИзИсточникаДанных("Номенклатура", "Номенклатура");
    ЭлементБлокировки.ИспользоватьИзИсточникаДанных("Склад",       "Склад");

    Блокировка.Заблокировать();

    // ... читать остатки и писать движения в той же транзакции ...

КонецПроцедуры
```

Главные правила: блокировать **до** чтения; `Исключительный` для записи и `Разделяемый` только для согласованного чтения; передавать `ИсточникДанных`, а не перебирать вручную; блокировать регистр, а не документ; не вызывать диалоги пользователя и длительные операции внутри транзакции; режим блокировки конфигурации - `Управляемый`.

**Подробный разбор - `locks-and-transactions.md`.** Там полная теория: границы транзакций, неявные и явные транзакции, контракт порядка блокировок для всего проекта, паттерны массовых операций, паттерн журнала статусов, диагностика по технологическому журналу (`TLOCK` / `TDEADLOCK`). При проектировании нового пути проведения или разборе взаимоблокировки читать его первым.

**Стандарт.** ИТС: «Управление блокировкой данных в транзакции», «Особенности проведения документов».

## 10. Фоновые задания из внешней обработки (БСП)

**Проблема.** `ДлительныеОперации` выполняются на сервере. Если обработка открыта через «Файл → Открыть» (то есть как внешний `*.epf`, а не из справочника `ДополнительныеОтчетыИОбработки`), БСП не находит обработку на сервере и `ВыполнитьВФоне` падает.

**Симптом.** «Метаданные не найдены» / «Не удалось получить обработку на сервере» при вызове `ДлительныеОперации.ВыполнитьВФоне` из формы внешней обработки.

**Шаблон - скопировать двоичный файл обработки на сервер через временное хранилище:**

```bsl
&НаКлиенте
Процедура ПриОткрытии(Отказ)
    Если ЭтоВнешняяОбработка() Тогда
        ОписаниеОповещения = Новый ОписаниеОповещения(
            "ОбработатьРезультатПомещенияФайлаОбработки", ЭтотОбъект);
        НачатьПомещениеФайлов(ОписаниеОповещения,
            ИмяФайлаОбработки(), Ложь, УникальныйИдентификатор);
    КонецЕсли;
КонецПроцедуры

&НаКлиенте
Процедура ОбработатьРезультатПомещенияФайлаОбработки(ПомещенныеФайлы, ОбработчикЗавершения) Экспорт
    Если ПомещенныеФайлы <> Неопределено Тогда
        ХранениеФайлаОбработки = КопияОбработкиНаСервере(ПомещенныеФайлы[0].Хранение);
    КонецЕсли;
КонецПроцедуры

&НаСервере
Функция КопияОбработкиНаСервере(Хранение)
    Результат = ПолучитьИмяВременногоФайла();
    ДвоичныеДанные = ПолучитьИзВременногоХранилища(Хранение);
    ДвоичныеДанные.Записать(Результат);
    Возврат Результат;
КонецФункции
```

**Шаблон - запуск фонового задания:**

```bsl
&НаСервере
Функция НачатьВыполнениеФоновогоЗаданияНаСервере()
    ЭтоВнешняяОбработка = ЭтоВнешняяОбработка();
    Если ЭтоВнешняяОбработка Тогда
        ИмяОбработки = ХранениеФайлаОбработки;
    Иначе
        ИмяОбработки = РеквизитФормыВЗначение("Объект").Метаданные().ПолноеИмя();
    КонецЕсли;

    ПараметрыЗадания = Новый Структура;
    ПараметрыЗадания.Вставить("ИмяОбработки", ИмяОбработки);
    ПараметрыЗадания.Вставить("ИмяМетода", "<имя процедуры в модуле объекта>");
    ПараметрыЗадания.Вставить("ПараметрыВыполнения", ПараметрыВыполненияОбработки);
    ПараметрыЗадания.Вставить("ЭтоВнешняяОбработка", ЭтоВнешняяОбработка);

    ПараметрыВыполнения = ДлительныеОперации.ПараметрыВыполненияВФоне(УникальныйИдентификатор);
    ПараметрыВыполнения.НаименованиеФоновогоЗадания = "<описание задания>";
    ПараметрыВыполнения.ЗапуститьВФоне = Истина;

    Возврат ДлительныеОперации.ВыполнитьВФоне(
        "ДлительныеОперации.ВыполнитьПроцедуруМодуляОбъектаОбработки",
        ПараметрыЗадания, ПараметрыВыполнения);
КонецФункции
```

**Обход безопасного режима в фоне.** Чтобы отключить проверку разрешений безопасного режима внутри фонового задания, создать новый экземпляр обработки без безопасного режима:

```bsl
Процедура ОбработкаДанныхВФоне(Параметры, АдресРезультата) Экспорт
    ЧастиИмени = СтрРазделить(ЭтотОбъект.Метаданные().ПолноеИмя(), ".");
    ЭтоВнешняяОбработка = (ВРег(ЧастиИмени[0]) = "ВНЕШНЯЯОБРАБОТКА");
    Если ЭтоВнешняяОбработка Тогда
        ОбработкаОбъект = ВнешниеОбработки.Создать(
            ЭтотОбъект.ИспользуемоеИмяФайла, Ложь,
            ОбщегоНазначения.ОписаниеЗащитыБезПредупреждений());
        Результат = ОбработкаОбъект.ОбработкаДанных(...);
    Иначе
        Результат = ОбработкаДанных(...);
    КонецЕсли;
    ПоместитьВоВременноеХранилище(Результат, АдресРезультата);
КонецПроцедуры
```

**Ограничения.**

- Фоновая процедура не может использовать реквизиты формы и табличные части обработки: все передавать через параметры.
- Серверная копия лежит во временном файле: хранить ее путь в реквизите формы (`ХранениеФайлаОбработки`) до завершения длительной операции.

**Стандарт.** Подсистема БСП «Длительные операции»; справка по `ДлительныеОперации.ВыполнитьПроцедуруМодуляОбъектаОбработки`. Требуется БСП 3.0+ и платформа 8.3.13+.

## Расширение сборника кейсов

При обнаружении нового типового подводного камня:

1. Добавить раздел по схеме «Проблема → Симптом → Шаблон → Стандарт».
2. Если решение зависит от версии платформы или БСП, указать версию явно.
3. Если есть минимальный воспроизводимый пример, включить его.
4. По возможности дать ссылку на ИТС, документацию платформы или конкретный модуль БСП.
