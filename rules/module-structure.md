# Шаблоны структуры модулей

Канонические имена областей - **русские, в стиле БСП**. Английские имена (`Public` / `Internal` / `Private`) использовать НЕЛЬЗЯ, кроме случая, когда вся конфигурация уже ведется в английской локали и области единообразно определены по всей кодовой базе.

Заголовочная политика по областям модулей - `coding-standards.md`, раздел «Области модулей».

## Общий модуль

```bsl
#Область ПрограммныйИнтерфейс

#КонецОбласти

#Область СлужебныйПрограммныйИнтерфейс

#КонецОбласти

#Область СлужебныеПроцедурыИФункции

#КонецОбласти
```

- `ПрограммныйИнтерфейс` - публичные экспортные процедуры и функции; то, что могут вызывать другие модули конфигурации.
- `СлужебныйПрограммныйИнтерфейс` - экспортные процедуры и функции только для собственных модулей проекта (соглашение БСП: не вызывать из стороннего кода).
- `СлужебныеПроцедурыИФункции` - внутренние вспомогательные методы, никогда не `Экспорт`.

## Модуль объекта и модуль менеджера

```bsl
#Если Сервер Или ТолстыйКлиентОбычноеПриложение Или ВнешнееСоединение Тогда

#Область ПрограммныйИнтерфейс

#КонецОбласти

#Область ОбработчикиСобытий

#КонецОбласти

#Область СлужебныеПроцедурыИФункции

#КонецОбласти

#КонецЕсли
```

Внешний блок препроцессора `#Если Сервер Или ТолстыйКлиентОбычноеПриложение Или ВнешнееСоединение Тогда` для модулей объектов и менеджеров **обязателен**.

## Модуль формы

```bsl
#Область ОбработчикиСобытийФормы

#КонецОбласти

#Область ОбработчикиСобытийЭлементовШапкиФормы

#КонецОбласти

#Область ОбработчикиСобытийЭлементовТаблицыФормыИмяТаблицы

#КонецОбласти

#Область ОбработчикиКомандФормы

#КонецОбласти

#Область СлужебныеПроцедурыИФункции

#КонецОбласти
```

Все 5 областей модуля формы **обязательны**, даже пустые. Для каждой табличной части формы создается отдельная область `ОбработчикиСобытийЭлементовТаблицыФормы<ИмяТаблицы>` (вместо `<ИмяТаблицы>` подставить фактическое имя табличной части).

## Общие правила

- Области внутри процедур и функций **запрещены**.
- Псевдообласти через комментарии **запрещены**: только `#Область` / `#КонецОбласти`.
- Канонические области не переименовывать, не удалять и не переупорядочивать. Если раздел пуст, оставить его пустым.
