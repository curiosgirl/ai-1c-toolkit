# Паттерны компоновки управляемых форм

Руководство по проектированию управляемых форм, выведенное из типовых конфигураций 1С. Использовать при построении формы, когда в требованиях пользователя не указано, где размещать элементы. Это знание о компоновке: оно применимо независимо от того, правится форма в EDT, Конфигураторе или через инструмент агента. Дополняет точку входа `forms.md`.

Имена элементов и групп ниже (`ГруппаШапка`, `Отбор[Поле]` и т.п.) - условные идентификаторы 1С; их следует сохранять на русском, как показано: это реальные имена, а не проза.

## Архетипы форм

### Форма документа

```
Шапка (горизонтальная, 2 колонки)
├─ Левая (вертикальная): НомерДата (Г: Номер + Дата "от"), Контрагент, Договор
├─ Правая (вертикальная): Организация, Подразделение, ЦеныИВалюта (гиперссылка-надпись)
Страницы
├─ Товары: таблица Объект.Товары
├─ Услуги: таблица Объект.Услуги (необязательно)
└─ Дополнительно: прочие реквизиты
Подвал (вертикальный)
├─ Итоги (горизонтальная): Всего, НДС, Скидка
└─ КомментарийОтветственный (горизонтальная): Комментарий + Ответственный
```

- Типичные события: `ПриСозданииНаСервере`, `ПриЧтенииНаСервере`, `ПриОткрытии`, `ПередЗаписьюНаСервере`, `ПослеЗаписиНаСервере`, `ПослеЗаписи`, `ОбработкаОповещения`.
- Свойства: `АвтоЗаголовок = Ложь`; командная панель со стандартными и глобальными командами.

### Форма обработки

```
Параметры (вертикальная)
├─ Группа полей ввода (Организация, Период, режимы работы)
├─ Информационные надписи (надпись, гиперссылка)
Рабочая область
├─ Таблица данных или Страницы с закладками
Кнопки действий
├─ Выполнить / Применить (кнопка по умолчанию)
├─ Закрыть (стандартная команда Close)
```

- Типичные события: `ПриСозданииНаСервере`, `ПриОткрытии`, `ОбработкаОповещения`.
- Свойства: `РежимОткрытияОкна = БлокироватьОкноВладельца` (для диалога); `АвтоЗаголовок = Ложь`.

### Форма списка

```
Отборы (группа: всегда горизонтальная)
├─ ГруппаОтбор[Поле] (Г): флажок + поле ввода (на каждый отбор)
Список (таблица, ДинамическийСписок)
├─ Колонки: поля-надписи (не ввод - данные только для чтения)
```

- Типичные события: `ПриСозданииНаСервере`, `ПриОткрытии`, `ОбработкаОповещения`, `ПриЗагрузкеДанныхИзНастроекНаСервере`.
- Свойства: `АвтоматическоеСохранениеДанныхВНастройках = Использовать` (запоминание отборов).
- Отборы: пара реквизитов на отбор - `Отбор[Поле]` (значение) + `Отбор[Поле]Использование` (булево, флажок включения).

### Форма элемента справочника

Простая:
```
ГруппаРеквизитов (горизонтальная)
├─ Наименование -> Объект.Description
└─ Код -> Объект.Code (при необходимости)
```

Сложная:
```
Главное (вертикальная)
├─ Наименование -> Объект.Description
├─ Параметры (горизонтальная, 2 колонки)
│  ├─ Левая: основные реквизиты
│  └─ Правая: второстепенные реквизиты
└─ КонтактныеДанные / Дополнительно (вертикальная)
```

- Типичные события: `ПриСозданииНаСервере`, `ПриЧтенииНаСервере`, `ПередЗаписьюНаСервере`, `ОбработкаОповещения`.

### Мастер (помощник)

```
Страницы (страницы, ПриСменеТекущейСтраницы)
├─ Шаг 1: описание + параметры
├─ Шаг 2: основная работа
└─ Шаг 3: результат
Кнопки (горизонтальная)
├─ Назад (команда), Далее (команда, кнопка по умолчанию), Выполнить (команда)
└─ Закрыть (стандартная команда Close)
```

- Свойства: `РежимОткрытияОкна = БлокироватьОкноВладельца`.

## Соглашения об именовании

### Группы

| Назначение | Имя | Тип |
|---------|------|------|
| Шапка | `ГруппаШапка` | горизонтальная |
| Левая колонка | `ГруппаШапкаЛевая` | вертикальная |
| Правая колонка | `ГруппаШапкаПравая` | вертикальная |
| Номер + дата | `ГруппаНомерДата` | горизонтальная |
| Подвал | `ГруппаПодвал` | вертикальная |
| Итоги | `ГруппаИтоги` | горизонтальная |
| Кнопки | `ГруппаКнопок` | горизонтальная |
| Страницы | `ГруппаСтраницы` / `Страницы` | страницы |
| Предупреждение | `ГруппаПредупреждение` | горизонтальная, видимость: Ложь |
| Дополнительный раздел | `ГруппаДополнительно` / `ГруппаПрочее` | вертикальная, сворачиваемая |

### Элементы

| Назначение | Имя |
|---------|------|
| Поле в таблице | `[Таблица][Поле]` |
| Итог | `Итоги[Поле]` |
| Гиперссылка-надпись | `[Поле]Надпись` |
| Отбор | `Отбор[Поле]` |
| Флажок отбора | `Отбор[Поле]Использование` |
| Кнопка команды | `[Команда]Кнопка` |
| Картинка баннера | `[Баннер]Картинка` |
| Надпись баннера | `[Баннер]Надпись` |
| Подменю | `Подменю[Действие]` |

### Обработчики событий

Имя обработчика = имя элемента + суффикс события на русском:

| Событие | Суффикс | Пример |
|-------|--------|---------|
| OnChange | ПриИзменении | `ОрганизацияПриИзменении` |
| StartChoice | НачалоВыбора | `КонтрагентНачалоВыбора` |
| Click | Нажатие | `ЦеныИВалютаНажатие` |
| OnEditEnd | ПриОкончанииРедактирования | `ТоварыПриОкончанииРедактирования` |
| OnStartEdit | ПриНачалеРедактирования | `ТоварыПриНачалеРедактирования` |

Обработчики уровня формы используют стандартные имена: `ПриСозданииНаСервере`, `ПриОткрытии`, `ПередЗакрытием`, `ОбработкаОповещения`.

## Принципы компоновки

1. **Порядок чтения.** Сверху вниз, слева направо. Самое важное содержимое - вверху.
2. **Шапка в две колонки.** Основные реквизиты слева (контрагент, склад), организационные справа (организация, подразделение).
3. **Кнопки действий внизу.** Главная кнопка - `кнопка по умолчанию`. `Закрыть` всегда последняя.
4. **Таблицы - основная область.** Табличные части занимают большую часть формы, обычно на страницах.
5. **Итоги рядом с таблицей.** В подвале, горизонтальная группа, все поля только для чтения.
6. **Отборы в отдельной зоне.** Над списком, горизонтальная группа (всегда горизонтальная), пара «флажок + поле» на каждый отбор.
7. **Скрытые элементы для состояний.** Баннеры и предупреждения по умолчанию невидимы, показываются программно.
8. **Гиперссылки-надписи для диалогов.** Поле-надпись с гиперссылкой и событием Нажатие - для открытия подчиненных форм (ЦеныИВалюта, УчетнаяПолитика).

## Расширенные паттерны (ERP)

Выведены из конфигурации «Управление предприятием» (ERP 8.3.24). Применять в сложных формах.

### Сворачиваемые группы

Для необязательных разделов - «Подписи», «Дополнительно», «Прочее». По умолчанию свернуты, экономят место.

```
ГруппаПодписи (вертикальная, сворачиваемая, по умолчанию свернута)
├─ Руководитель -> Объект.Руководитель
└─ ГлавныйБухгалтер -> Объект.ГлавныйБухгалтер
```

Использовать вертикальную группу с поведением сворачивания и включенным свернутым состоянием.

### Баннер состояния

Группа «картинка + надпись» без заголовка, по умолчанию скрыта. Показывается программно при определенных условиях (просрочено, заблокировано, информационное сообщение).

```
ГруппаПредупреждение (горизонтальная, показыватьЗаголовок: Ложь, видимость: Ложь)
├─ [Картинка] ПредупреждениеКартинка -> StdPicture.Information
└─ [Надпись] ПредупреждениеНадпись (ограниченная максимальная ширина, цвет текста по стилю)
```

### Всплывающее меню в командной панели

Группирует связанные команды (печать, отправка, выгрузка) в одну кнопку-меню с иконкой.

```
[КомандПанель] КоманднаяПанель
├─ [Подменю] ПодменюПечать (картинка: StdPicture.Print, представление: Картинка)
│  ├─ [Кнопка] ПечатьНакладная -> Печать [команда]
│  └─ [Кнопка] ПечатьСчет -> ПечатьСчет [команда]
└─ [Подменю] ПодменюОтправить (картинка: StdPicture.SendByEmail)
   └─ [Кнопка] ОтправитьПоПочте -> Отправить [команда]
```

### Форма без стандартной командной панели

Для модальных диалогов и мастеров: отключить стандартную командную панель и управлять кнопками вручную.

```
свойства: РасположениеКоманднойПанели = Нет, РежимОткрытияОкна = БлокироватьВесьИнтерфейс
Содержимое (вертикальная)
├─ ... рабочая область ...
ГруппаКнопок (горизонтальная)
├─ Назад (команда), Далее (команда, кнопка по умолчанию)
└─ Закрыть (стандартная команда Close)
```

### Гиперссылка-надпись для открытия подчиненных форм

Поле-надпись с гиперссылкой и событием Нажатие - вместо кнопки. Частый прием для «ЦеныИВалюта», «УчетнаяПолитика» и подобных.

```
[ПолеНадписи] ЦеныИВалютаНадпись -> ЦеныИВалюта (гиперссылка) {Нажатие}
```
