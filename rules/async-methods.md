# Асинхронные методы в 1С (Асинх / Ждать / Обещание)

Правила использования асинхронного механизма, появившегося в платформе 8.3.18+.

Применимо к: клиентскому коду с асинхронными вызовами (`&НаКлиенте`).

Авторитетная справка: `architecture.md`, раздел «Асинхронность и модальность». Этот файл дает практические паттерны и подводные камни.

---

## Основные принципы

1. Каждая новая асинхронная функция (суффикс `Асинх`) возвращает объект `Обещание`.
2. `Ждать` - оператор ожидания. Код после `Ждать` не выполняется, пока обещание не разрешится.
3. Методы `*Асинх` можно вызывать **только внутри** процедур и функций, объявленных с ключевым словом `Асинх`.
4. У `Обещания` три состояния: **Ожидание**, **Успех**, **Провал**.
5. Механизм работает **только на клиенте** (`&НаКлиенте`).

---

## Соответствие старых и новых методов

Предпочитать новый синтаксис `*Асинх` вместо `Показать*` с `ОписаниеОповещения`:

| Модальный (запрещен) | С обратным вызовом | Новый Асинх |
|---|---|---|
| `Предупреждение()` | `ПоказатьПредупреждение()` | `ПредупреждениеАсинх()` |
| `Вопрос()` | `ПоказатьВопрос()` | `ВопросАсинх()` |
| `ОткрытьЗначение()` | `ПоказатьЗначение()` | `ОткрытьЗначениеАсинх()` |
| `ВвестиЧисло()` | `ПоказатьВводЧисла()` | `ВвестиЧислоАсинх()` |
| `НайтиФайлы()` | `НачатьПоискФайлов()` | `НайтиФайлыАсинх()` |
| `ПоместитьФайлы()` | `НачатьПомещениеФайлов()` | `ПоместитьФайлыНаСерверАсинх()` |

---

## Возвращаемые значения (результат `Ждать`)

| Метод | Результат `Ждать Обещание` |
|---|---|
| `ПредупреждениеАсинх` | `Неопределено` |
| `ВопросАсинх` | `КодВозвратаДиалога` |
| `ОткрытьЗначениеАсинх` | `Неопределено` |
| `ВвестиЧислоАсинх` | `Число` |
| `НайтиФайлыАсинх` | `Массив` объектов `Файл` |
| `ПоместитьФайлыНаСерверАсинх` | `Массив` `ОписаниеПомещенногоФайла` (успех) / `Неопределено` (сбой) |

## Базовый шаблон

```bsl
&НаКлиенте
Асинх Процедура МояПроцедура()

    Обещание = ВопросАсинх("Продолжить?", РежимДиалогаВопрос.ДаНет);
    Результат = Ждать Обещание;

    Если Результат = КодВозвратаДиалога.Да Тогда
        // Действие
    КонецЕсли;

КонецПроцедуры
```

## Критические правила

### 1. Без `Ждать` исключения теряются молча

Если вызвать асинхронную функцию без `Ждать` и внутри произойдет исключение, оно **поглотится без следа**. Код продолжит работу, как будто ничего не случилось.

```bsl
// ОПАСНО: исключение внутри ВызватьОшибку() потеряется!
Процедура МояПроцедура(Команда)
    ВызватьОшибку(); // Асинхронная функция вызвана без Ждать
КонецПроцедуры

Асинх Функция ВызватьОшибку()
    ВызватьИсключение "ошибка!"; // никто этого не увидит
КонецФункции
```

**Правило.** Всегда использовать `Ждать` при вызове `Асинх` функций, если важны результат или обработка ошибок. Пропускать `Ждать` только в сценариях «выстрелил и забыл», где результат и возможные ошибки намеренно игнорируются.

### 2. `Асинх` в обработчиках событий формы НЕ блокирует

Обработчики событий формы (`ПриОткрытии`, `ПередЗакрытием`), объявленные с `Асинх`, **ведут себя не так, как ожидается**: платформа не дожидается их завершения.

```bsl
// НЕ РАБОТАЕТ! Форма все равно откроется, Отказ = Истина игнорируется.
&НаКлиенте
Асинх Процедура ПриОткрытии(Отказ)
    Отказ = Истина;                    // платформа уже пошла дальше
    ВызватьИсключение "ошибка!";       // пользователь увидит ошибку, но форма уже открыта
КонецПроцедуры
```

**Правило.** **Не** делать обработчики событий формы (`ПриОткрытии`, `ПередЗакрытием`, `ПриЗаписиНаСервере` и т.п.) асинхронными. Параметр `Отказ` и любое влияние на ход выполнения формы будут проигнорированы. Вместо этого вызывать отдельную `Асинх` процедуру из обычного обработчика.

### 3. Обработчики команд - асинхронность допустима

В отличие от обработчиков событий формы, обработчики команд **можно** безопасно объявлять `Асинх`:

```bsl
&НаКлиенте
Асинх Процедура МояКоманда(Команда)
    Обещание = ВвестиЧислоАсинх(1, "Укажите число");
    Результат = Ждать Обещание;
КонецПроцедуры
```

## Паттерн: вопрос при открытии формы

`ПриОткрытии` - обычная процедура, вызывающая отдельную `Асинх` процедуру:

```bsl
&НаКлиенте
Процедура ПриОткрытии(Отказ)
    ЗадатьВопросПриОткрытии();
КонецПроцедуры

&НаКлиенте
Асинх Процедура ЗадатьВопросПриОткрытии()

    Обещание = ВопросАсинх("Продолжить работу?",
        РежимДиалогаВопрос.ДаНет, , КодВозвратаДиалога.Да);
    Результат = Ждать Обещание;

    Если Результат <> КодВозвратаДиалога.Да Тогда
        ЭтаФорма.Закрыть();
    КонецЕсли;

КонецПроцедуры
```

---

## Паттерн: вопрос при закрытии формы

Переменная-флаг предотвращает рекурсию:

```bsl
&НаКлиенте
Перем ВопросПриЗакрытииЗадан;

&НаКлиенте
Процедура ПередЗакрытием(Отказ, ЗавершениеРаботы,
        ТекстПредупреждения, СтандартнаяОбработка)

    Если НЕ ВопросПриЗакрытииЗадан Тогда
        ЗадатьВопросПриЗакрытии();
        Отказ = Истина;
    КонецЕсли;

КонецПроцедуры

&НаКлиенте
Асинх Процедура ЗадатьВопросПриЗакрытии()

    Обещание = ВопросАсинх("Закрыть форму?",
        РежимДиалогаВопрос.ДаНет, , КодВозвратаДиалога.Да);
    Результат = Ждать Обещание;

    Если Результат = КодВозвратаДиалога.Да Тогда
        ВопросПриЗакрытииЗадан = Истина;
        ЭтаФорма.Закрыть();
    КонецЕсли;

КонецПроцедуры

ВопросПриЗакрытииЗадан = Ложь;
```

## Паттерн: работа с файлами

```bsl
&НаКлиенте
Асинх Процедура ЗагрузитьФайлыНаСервер()

    Обещание = НайтиФайлыАсинх(ПутьКПапке, "*.*", Ложь);
    НайденныеФайлы = Ждать Обещание;

    ДобавляемыеФайлы = Новый Массив;
    Для Каждого НайденныйФайл Из НайденныеФайлы Цикл
        Описание = Новый ОписаниеПередаваемогоФайла;
        Описание.Имя = НайденныйФайл.ПолноеИмя;
        ДобавляемыеФайлы.Добавить(Описание);
    КонецЦикла;

    Обещание = ПоместитьФайлыНаСерверАсинх(
        , , ДобавляемыеФайлы, ЭтаФорма.УникальныйИдентификатор);
    Результат = Ждать Обещание;

КонецПроцедуры
```

## Методы HTTP (платформа 8.3.21+)

`HTTPСоединение` предоставляет асинхронные аналоги (суффикс `Асинх`): `ВызватьHTTPМетодАсинх`, `ЗаписатьАсинх`, `ПолучитьАсинх` и др. Действуют те же правила: вызывающий должен быть `Асинх`, использовать `Ждать` для получения результата и всплытия исключений.
