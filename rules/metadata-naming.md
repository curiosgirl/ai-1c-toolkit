# Стандарты разработки: именование метаданных и общие правила

**Когда открывать:** при именовании и размещении объектов метаданных, реквизитов, элементов форм и ролей, при выборе типа объекта метаданных, при правке типового кода конфигурации.

Параметр `{PREFIX}` задается в `../project-profile.md`.

## Правка типового кода

Типовой код конфигурации правится минимально и только в пределах задачи. История правок хранится в git.

## Общие правила

- `TODO` / `FIXME` содержат ссылку на задачу: `// TODO No.14752: описание`.
- **Псевдообласти через комментарии ЗАПРЕЩЕНЫ**: только `#Область` / `#КонецОбласти`.

## Именование метаданных

| Элемент | Правило |
|---|---|
| Новые объекты метаданных | Префикс `{PREFIX}` в имени (например, `{PREFIX}СуммаДоговора`) |
| Синонимы объектов | Без префикса |
| Новые роли | Префикс `{PREFIX}` |
| Подсистемы | `{PREFIX}ДобавленныеОбъекты` и `{PREFIX}ИзмененныеОбъекты` |
| Реквизиты типовых объектов | Префикс `{PREFIX}` |
| Элементы форм на типовых формах | Префикс `{PREFIX}` |

**Если `PREFIX` пуст** в профиле проекта, плейсхолдер `{PREFIX}` превращается в пустую строку во всех правилах выше (например, `{PREFIX}СуммаДоговора` -> `СуммаДоговора`).

**Внутри нетиповых (новых) объектов** (в имени которых уже есть `{PREFIX}`):

- реквизиты, табличные части, элементы форм, команды, процедуры - **БЕЗ префикса**.

Дополнительно:

- Все новые объекты размещать в подсистемах.
- Составные типы, используемые многократно, оформлять через `ОпределяемыйТип`.
- При работе в среде EDT руководствоваться навыком `skills/edt-metadata/SKILL.md`: обеспечивать глобальную уникальность UUID, проверять существование ссылочных объектов метаданных и контролировать отсутствие дубликатов с помощью `python skills/edt-metadata/scripts/check_uuid_duplicates.py`.

### Выбор типа объекта

| Задача | Тип объекта |
|---|---|
| Справочные данные | `Справочник` |
| Бизнес-операции | `Документ` |
| Накопление количеств и сумм | `РегистрНакопления` |
| Произвольные данные с измерениями | `РегистрСведений` |
| Пользовательские отчеты | `Отчет` (с СКД) |
| Обработка данных | `Обработка` |
| Фиксированный набор значений | `Перечисление` |
