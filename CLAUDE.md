# Инструкции разработки 1С для Claude Code

Правила, навыки и субагенты проекта описаны в `AGENTS.md`, он подключается ниже целиком. Читать его перед любой работой с BSL-кодом, метаданными, тестами и Merge Request / Pull Request. Списки навыков и субагентов здесь не повторяются: реестр один.

@AGENTS.md

## Особенности Claude Code

- Субагенты загружаются из `.claude/agents/`, их инструкции лежат в `agents/`.
- Личные настройки разработчика (`workflow/local.md`, `.mcp.json`, содержимое каталогов `.claude` и `.cursor`) в репозиторий не коммитятся (см. `.gitignore`). Исключения - части пакета: `.cursor/rules/`, `.cursor/agents/`, `.claude/agents/`.
- Свои дополнения к правилам и сопоставление MCP-ролей держать в `workflow/local.md`.
